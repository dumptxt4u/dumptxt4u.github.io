Ordinary Differential Equations (Module 3)

S2 B.Tech - Vector Calculus, Differential Equations & Transforms

Homogeneous Linear DE (Repeated many times)

Solve:

(D² + 4D + 13)y = 0

OR

y'' + 6y' + 9y = 0
Repeated in: Dec 2019, July 2021, Jan 2024 etc.
Characteristic equation, complex roots
Non-homogeneous - Undetermined Coefficients

Solve:

y'' - 4y' + 4y = e^{2x} + x

OR

y'' + y = x cos x
Very common (Jan 2024, June 2022, July 2021)
Particular integral using undetermined coefficients
Variation of Parameters

Using variation of parameters, solve:

y'' + y = sec x

OR

y'' - y = e^x / x
Repeated almost every year
Wronskian method
Cauchy-Euler Equation

Solve:

x²y'' - 3xy' + 4y = 0

OR

2x²y'' + 5xy' - 3y = 0
Frequently asked (June 2023 onwards)
Euler-Cauchy type
Higher Order / System

Solve the system:

(D+1)x + (D-1)y = e^t
(D-1)x + (D+1)y = 0

OR

y''' - 3y'' + 3y' - y = e^x
Higher order linear DE with constant coefficients
Initial Value Problem

Solve with IC:

y'' + 3y' + 2y = 0, y(0)=1, y'(0)=0

OR

y'' + y = 30e^x, y(0)=3, y'(0)=-3
Common in Part B (14 marks)
Tips for KTU Exam
  • • Always check Wronskian for linear independence
  • • Practice both undetermined coefficients and variation of parameters
  • • Cauchy-Euler: Use substitution x = e^t
  • • 14-mark questions usually combine homogeneous + particular solution
  • • Recent trends: More focus on Variation of Parameters & applications
